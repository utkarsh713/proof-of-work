# AI Verification Service

AI-powered verification service for the Proof of Work platform.

This service verifies submitted public-work evidence by analyzing uploaded
before/after images and checking available image metadata such as GPS
location and timestamps.

## Features

- Before and after image verification
- Image metadata extraction
- GPS location verification
- Timestamp verification
- GPS distance calculation
- AI-based image verification
- Work description-based verification
- REST API using FastAPI
- JSON verification response

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pillow
- AI/ML
- EXIF Metadata

# proof-of-work

A decentralized platform for verifying public works using AI, GPS, timestamps, before/after evidence, and citizen verification.

## Project Modules

- Frontend: React
- Backend: Spring Boot
- Database: PostgreSQL
- AI Service: Python
- Verification: AI + GPS + Timestamp + Citizen Feedback
